Simulator Sistem Non-Linier

Pilih salah satu dari 5 soal, atau tulis sistem sendiri. Program mencari titik kesetimbangan dengan metode Newton-Raphson, lalu menghitung Jacobian, nilai eigen, dan jenis kestabilannya.

Rentang x dan y adalah daerah pencarian titik kesetimbangan. Tulis pangkat dengan ^, dan gunakan sin, cos, exp, sqrt, pi. Untuk bilangan negatif berpangkat, beri kurung, misalnya -(x^2).

Cara membaca hasil (sistem 2 dimensi)

Hitung trace (tr) dan determinan (det) dari Jacobian di setiap titik.
det < 0: saddle (tidak stabil).
det > 0 dan tr² − 4·det ≥ 0: node. Stabil (sink) jika tr < 0, tidak stabil (source) jika tr > 0.
det > 0 dan tr² − 4·det < 0: spiral. Stabil jika tr < 0, tidak stabil jika tr > 0.
det = 0 atau tr = 0 dengan eigenvalue imajiner: linearisasi tidak cukup untuk menyimpulkan kestabilan.
